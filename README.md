# ClearQuote-iOS-SDK-Demo-app

A demo app with [ClearQuoteSDK](https://github.com/clearquotetech/cq-ios-sdk) integrated.

For ClearQuoteSDK integration details, see the [integration guide](https://docs.google.com/document/d/1eqHUg3L7mqA4E8vqslzpLoqoC_8qxv7wTUn_JneKQmY/edit?usp=sharing).

## Requirements

- **Xcode 16 or above**
- **An iPhone device** (physical device required to run the app)

## Steps to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/clearquotetech/ClearQuote-iOS-SDK-Demo-app.git
   cd ClearQuote-iOS-SDK-Demo-app
   ```

2. Install dependencies with CocoaPods:
   ```bash
   pod install
   ```

3. Open `CQ-iOS-SDK-Demo.xcworkspace` in Xcode, select your iPhone as the run destination, and build and run the app.
