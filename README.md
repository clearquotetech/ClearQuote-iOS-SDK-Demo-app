# ClearQuote-iOS-SDK-Demo-app

A demo app with [ClearQuoteSDK](https://github.com/clearquotetech/cq-ios-sdk) integrated.

For the ClearQuoteSDK integration document, see [ClearQuote Native iOS SDK Integration Guide](<ClearQuote Native IOS SDK Integration guide.pdf>).

## Requirements

- **Xcode 27 or above**
- **An iPhone device** (physical device required to run the app)

## Steps to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/clearquotetech/ClearQuote-iOS-SDK-Demo-app.git
   cd ClearQuote-iOS-SDK-Demo-app
   ```

2. Open `CQ-iOS-SDK-Demo.xcodeproj` in Xcode. Swift Package Manager will resolve `ClearQuoteSDK` automatically.

3. Select your iPhone as the run destination, then build and run the app.
